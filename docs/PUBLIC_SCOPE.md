# 공개 범위

대상: KAIST 캠퍼스 안전 GIS 플랫폼

GIS 화면·서버와 가스·불꽃·화재 수신 모듈을 단독 개발했습니다. 기존 사내 공통 제품과 외부 장비·SDK는 직접 개발 범위에 포함하지 않습니다.

## 원본과 구분

- 최신 작업 브랜치의 소스를 선별했으며 과거 커밋을 공개 저장소로 가져오지 않습니다. 일부 최신 수정 브랜치는 사내 기본 브랜치에 아직 병합되지 않았을 수 있습니다.
- 운영 application 설정·JSON 데이터·로그·압축 파일·JAR·원본 폰트·영상·SDK와 GitLab CI·배포·에이전트 설정은 제외했습니다.
- 운영 IP·고정 키·토큰·비밀번호·사내 연락처 패턴을 검사하고 예시값으로 대체했습니다. 실제 비밀값은 이 문서에 기록하지 않습니다.
- 원본 바이너리의 OCR·실제 자격증명 유효성 시험·외부 시스템 접속은 하지 않았습니다.
- 사내 Maven 주소를 제거했으며 비공개 공통 라이브러리는 포함하지 않습니다. 따라서 서버 소스는 별도의 어댑터와 DB 설정 없이는 실행할 수 없습니다.
- 새 이력으로 공개해도 기존 GitHub의 옛 커밋 주소·캐시·복사본이 자동 삭제되는 것은 아닙니다. 사용 중인 기존 노출 인증정보는 별도 폐기·교체가 필요합니다.

## 검증

- 설치: npm install --ignore-scripts --legacy-peer-deps
- 빌드: package.json의 build 스크립트. CRA 검증 시 CI=false, GENERATE_SOURCEMAP=false, DISABLE_ESLINT_PLUGIN=true 적용.
- 화면 기본 빌드만 검증했으며 Java 서버 빌드·전체 동작·성능·UI·의존성 취약점 해결을 완료한 것은 아닙니다.
- 구형 의존성 보안 경고는 남아 있으며 임의로 숨기거나 보안 검사 0건이라고 표시하지 않습니다.

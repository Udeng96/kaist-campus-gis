# KAIST 캠퍼스 안전 GIS 플랫폼

캠퍼스의 건물·시설·CCTV와 가스·불꽃·화재 이벤트를 지도에서 확인하는 플랫폼입니다.

## 담당 범위

GIS 화면·서버와 가스·불꽃·화재 수신 모듈을 단독 개발했습니다. 기존 사내 공통 제품과 외부 장비·SDK는 직접 개발 범위에 포함하지 않습니다.

## 주요 기능

- 건물·시설·센서·CCTV 정보의 지도 표출과 조회
- 가스 데이터 조회·폴링, 이벤트 기록과 WebSocket 전달
- 불꽃 이벤트 수신 및 중복 이벤트 처리
- 화재 TCP 스트림·패킷 처리와 이벤트 연계
- 날씨·특보 및 순찰 이벤트 조회

## 구성

- `kaist-gis`
- `kaist-gas`
- `kaist-flame`
- `kaist-fire_module`

프론트엔드는 React·TypeScript 기반이며 지도·차트와 상태 관리 코드를 포함합니다. Java/Spring 기반 서버 소스가 함께 있으며 모듈별 세부 의존성은 각 `package.json`과 `pom.xml`에서 확인할 수 있습니다.

## 화면 빌드

```sh
cd modules/kaist-gis/front
npm ci --ignore-scripts --legacy-peer-deps
npm run build
npm run dev
```

Windows에서는 짧은 작업 경로를 사용합니다. 설치된 의존성을 별도로 동봉하지 않으며 Node.js 24 환경에서 기본 빌드를 확인했습니다. 구형 CRA 프로젝트의 검증 빌드는 소스맵과 ESLint 플러그인을 끈 상태로 실행했습니다. 스타일 검사·전체 UI 검증은 수행하지 않았습니다.

## 공개 소스의 범위

- 원본 Git 이력, 운영 설정·로그·실데이터·업로드 파일과 사내 바이너리를 포함하지 않습니다.
- 운영 주소와 고정 인증 문자열을 예시값으로 대체했습니다. 실제 인증값은 브라우저 코드나 환경변수에 넣지 않습니다.
- 원본 이미지·아이콘은 생성한 예시 자산으로 대체하고 폰트·원본 음원은 제외 또는 무음으로 교체했습니다.
- 포함된 CCTV SDK 경로는 외부 통신을 하지 않는 데모 어댑터입니다. 실제 CCTV·장비 제어 기능을 제공하지 않습니다.
- 서버는 다중 DB·사내 공통 라이브러리·외부 장비 및 인증 시스템이 필요한 참고 소스입니다. 설정 예시는 전체 실행 설정이 아닙니다.

## 검증과 제한

화면의 기본 빌드를 확인했습니다. 원본의 의존성 버전을 유지했으며 npm 보안 경고가 남아 있습니다. 이번 공개 준비에서는 대규모 라이브러리 업그레이드를 하지 않았습니다. 이 소스를 운영 배포본이나 보안 검증 완료 서비스로 설명하지 않습니다.

일부 기존 CSS 자산 참조 경고가 남을 수 있으며 원본 화면의 디자인을 재현한 데모가 아닙니다. Java 서버 빌드, 실제 DB·인증·센서·CCTV 연동과 전체 UI 흐름은 검증하지 않았습니다. 자세한 변경 범위는 [공개 범위](docs/PUBLIC_SCOPE.md)를 참고하세요.

의존성 검사 기록: 총 22건(심각 1, 높음 14, 보통 6, 낮음 1). 구형 도구와 전이 의존성을 포함한 npm 검사 결과이며, 실제 악용 가능성을 개별 판정한 수치는 아닙니다.
